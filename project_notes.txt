FASTAPI AUTOMATION TASK PROJECT - REVISION NOTES

1. Project Goal
This project creates a FastAPI backend that:
- receives an automation task
- validates incoming data
- verifies API key authentication
- calls an external API
- combines data
- returns a clean JSON response
- runs a small background task after sending the response

3. Environment Variable

.env file:

API_KEY=my-automation-key-123

Purpose:
- keep API key outside source code
- avoid hardcoding secrets

Used with:

load_dotenv()
API_KEY = os.getenv("API_KEY")


4. TaskRequest Model

class TaskRequest(BaseModel):
    user_id: int = Field(gt=0)
    task: str = Field(min_length=5)
    priority: int = Field(ge=1, le=5)

Purpose:
TaskRequest defines and validates incoming JSON data.

Validation:
- user_id must be greater than 0
- task must have minimum 5 characters
- priority must be between 1 and 5


5. TaskResponse Model

class TaskResponse(BaseModel):
    user_id: int
    user_name: str
    email: str
    task: str
    priority: int
    message: str

Purpose:
TaskResponse defines the structure of outgoing JSON data.

Remember:

TaskRequest  -> incoming data
TaskResponse -> outgoing data


6. API Key Authentication

Client sends:

X-API-Key: my-automation-key-123

FastAPI reads this using:

Header()

Authentication function:

verify_api_key()

If API key is wrong:

401 Unauthorized

Depends(verify_api_key)

Purpose:
Runs authentication before the main endpoint.


7. Main Endpoint

POST /process_task

Purpose:
Receives automation task data and starts processing.

It receives:

task_data: TaskRequest

This contains:

task_data.user_id
task_data.task
task_data.priority


8. External API Call

External API:

https://jsonplaceholder.typicode.com/users/{user_id}

Example:

user_id = 2

FastAPI calls:

https://jsonplaceholder.typicode.com/users/2

Used:

httpx.AsyncClient()

and:

await client.get()

Purpose:
FastAPI calls another external service without blocking while waiting.


9. async and await

async def:
Defines an asynchronous endpoint.

await:
Waits for an asynchronous operation without blocking the server.

Useful for:
- AI APIs
- CRM APIs
- external services
- databases
- network calls


10. External API Response

External API returns user information like:

name
email

Converted using:

user_data = response.json()

Then accessed using:

user_data["name"]
user_data["email"]


11. Combining Data

Client gives:

user_id
task
priority

External API gives:

name

FastAPI combines both and returns:

user_id
user_name

12. HTTPException

Used for proper API errors.

Examples:

401
Invalid API Key

404
User not found

503
External service unavailable

Syntax:

raise HTTPException(
    status_code=404,
    detail="User not found"
)


13. response_model

Endpoint uses:

response_model=TaskResponse

Purpose:
- validates outgoing response
- keeps response structure clean
- helps Swagger documentation
- prevents unwanted fields from being exposed


14. BackgroundTasks

BackgroundTasks allows FastAPI to:
- send main response first
- run small extra work afterward

Used:

background_tasks.add_task(
    save_log,
    task_data.user_id,
    task_data.task
)

Background function:

save_log()

For practice it prints:
- user ID
- task information

Real use cases:
- logging
- notification
- sending email
- small follow-up actions


15. Complete Request Flow

1. Client sends POST request.
2. Client sends JSON body.
3. Client sends X-API-Key header.
4. FastAPI receives request.
5. verify_api_key() checks authentication.
6. TaskRequest validates JSON data.
7. process_task() starts.
8. FastAPI builds external API URL.
9. httpx calls external API.
10. await waits for response.
11. response.json() converts JSON to Python data.
12. FastAPI combines task data and user data.
13. Background log task is scheduled.
14. TaskResponse validates outgoing response.
15. Client receives final JSON.
16. save_log() runs in background.

19. When to Use FastAPI

Use FastAPI when another system needs to communicate with Python or AI logic over HTTP.

Examples:
- n8n calling Python AI logic
- frontend calling AI backend
- receiving webhook
- exposing AI model through API
- connecting multiple applications

FastAPI is not required for every Python automation script.
